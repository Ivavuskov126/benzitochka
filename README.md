# ⛽ Бенз и точка

> **Бенз и точка** — быстрый и простой поиск необходимого бензина в два клика!

Telegram-бот и геосервис от продуктовой IT-компании **ООО «Й БЕНЗИНА НЕТУ»**, созданный для автовладельцев, водителей такси, курьеров и жителей Смоленска.

---

## 📌 О проекте

Проект решает проблему быстрого поиска выгодного топлива рядом с водителем. Бот позволяет сэкономить время и деньги, предоставляя актуальную информацию о заправках в реальном времени.

### Основные возможности (MVP)
* 📍 **Поиск ближайших АЗС** по текущей геолокации пользователя.
* 💰 **Актуальные цены на топливо** (АИ-92, АИ-95, АИ-100 и ДТ) на основе API «ГдеБЕНЗ».
* 🗺️ **Построение маршрута** до выбранной заправочной станции.
* 🤝 **Взаимопомощь пользователей** — система обратной связи и актуальности данных.

---

## 💎 Наши ценности

1. **Взаимопомощь** — пользователи помогают друг другу находить лучшее топливо.
2. **Простота** — интуитивно понятный интерфейс и результат в два клика.
3. **Надёжность** — широкая поддержка и актуальность данных.

---

## 🛠 Технологический стек и направления

* **Платформа:** Telegram Bot API
* **Backend & Парсинг:** Python, работа с внешними API («ГдеБЕНЗ»), аналитика данных
* **Базы данных:** SQL / PostgreSQL
* **Инфраструктура:** Linux, Docker, Git, CI/CD
